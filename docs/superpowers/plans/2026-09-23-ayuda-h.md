# Ayuda con la tecla H (sub-proyecto 8, v3.9.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Overlay de ayuda (tecla H) en todas las pantallas: oscurece, numera cada zona/botón y explica qué hace.

**Architecture:** Registro `ui/ayuda.py` (items por pantalla, estáticos o calculados por estado) + dibujo/gestión de eventos centralizados en `main.py`. Las pantallas no cambian, salvo exponer rects que hoy sean locales (constantes/funciones `rect_*`).

**Tech Stack:** Python 3.10+, Pygame; tests con runner propio.

**Spec:** `docs/superpowers/specs/2026-09-23-ayuda-h-design.md` · **Depende de:** sub-proyectos 3-6 terminados.

## Global Constraints
- Comentarios `# v3.9.0: ...`; sin commits; suite en verde.
- Textos ≤ 110 caracteres, español, explican qué hace y su tecla si tiene.
- `estado['texto_activo'] = True` lo ponen las pantallas mientras hay un campo de texto con foco (buscador por nombre, editor, overlay de filtros, montos); con eso H no abre la ayuda.

## Review Focus
- H mientras se escribe el nombre en el buscador → se escribe "h", no abre la ayuda. Test en Task 1 (`test_h_con_texto_activo`).
- Ayuda abierta y clic sobre un botón → la pantalla no recibe el clic. Test en Task 1 (`test_eventos_bloqueados`).
- Pantalla con más de 10 items → la leyenda pagina con ←/→ y no se sale de la pantalla. Test en Task 1 (`test_paginado`).
- Pantalla nueva sin entrada en AYUDA → overlay genérico ("Esta pantalla aún no tiene ayuda detallada") en vez de error. Test en Task 1 (`test_pantalla_sin_ayuda`).
- Rect de un item que depende del estado (pestaña del hub) → cambia al cambiar de pestaña. Test en Task 2 (`test_hub_por_pestana`).

## Reparto
Un subagente: Task 1 y luego Task 2 (o dos subagentes: Task 2 partida por grupos de pantallas cuando Task 1 esté).

```python
from alpha_football.ui import ayuda as AY

def kd(k, u=''): return pygame.event.Event(pygame.KEYDOWN, key=k, mod=0, unicode=u)

def test_h_abre_y_cierra():
    e = {}
    assert AY.manejar_evento(e, kd(pygame.K_h, 'h'), 'league_screen') and e['ayuda_abierta']
    assert AY.manejar_evento(e, kd(pygame.K_ESCAPE), 'league_screen') and not e['ayuda_abierta']

def test_h_con_texto_activo():
    e = {'texto_activo': True}
    assert not AY.manejar_evento(e, kd(pygame.K_h, 'h'), 'buscador_screen') and not e.get('ayuda_abierta')

def test_eventos_bloqueados():
    e = {'ayuda_abierta': True}
    ev = pygame.event.Event(pygame.MOUSEBUTTONDOWN, button=1, pos=(100, 100))
    assert AY.manejar_evento(e, ev, 'league_screen')

def test_paginado():
    AY.AYUDA['_prueba'] = [(pygame.Rect(10 + i * 20, 10, 10, 10), f"T{i}", "texto") for i in range(23)]
    e = {'ayuda_abierta': True}
    AY.dibujar(screen, '_prueba', e); assert e.get('ayuda_pagina', 0) == 0
    AY.manejar_evento(e, kd(pygame.K_RIGHT), '_prueba'); assert e['ayuda_pagina'] == 1
    AY.manejar_evento(e, kd(pygame.K_RIGHT), '_prueba'); AY.manejar_evento(e, kd(pygame.K_RIGHT), '_prueba')
    assert e['ayuda_pagina'] == 2                      # 23 items / 10 = 3 páginas
    AY.dibujar(screen, '_prueba', e)
    del AY.AYUDA['_prueba']

def test_pantalla_sin_ayuda():
    e = {'ayuda_abierta': True}
    assert AY.items('no_existe', e) == [] and AY.dibujar(screen, 'no_existe', e) is None
```
